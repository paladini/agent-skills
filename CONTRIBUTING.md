# Contributing

Thank you for improving these Agent Skills.

1. Open an issue describing the workflow or failure mode.
2. Keep core instructions in `SKILL.md` and move detailed guidance into `references/`.
3. Add deterministic scripts only when they replace repeated or fragile work.
4. Test scripts and run the skill validator.
5. Submit a focused pull request describing the behavior change and validation evidence.

Do not include credentials, private prompts, personal data, generated filler, or claims that cannot be verified.
